# Tutorials

*Tutorial — a guided walkthrough. Follow every step in order; you will end up with a working result.*

Start here if you are new to the operator. A tutorial makes every decision for
you and tells you what to expect after each step, so you can get to a working
system before you have to choose anything.

- **[Your first Home Assistant instance](first-instance.md)** — from a cluster
  with nothing installed to a Home Assistant you can log into.
- **[Your first automation as code](first-automation.md)** — create, change and
  delete a Home Assistant automation without opening its UI.

Once you have a running instance, the [how-to guides](../how-to/index.md) cover
individual tasks, and the [explanations](../explanation/index.md) cover why the
operator behaves the way it does.
